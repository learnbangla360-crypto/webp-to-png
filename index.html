Expert tips and common mistakes

Expect a bigger file

WebP compresses far better than PNG, so a 80 KB WebP photo can become a PNG of several hundred KB or more. For photos without transparency, JPG is usually smaller. Try the WebP to JPG Converter.

Don't expect lost detail to return

If the WebP was saved with lossy compression, the PNG copies those pixels as they are. It won't look sharper.

Pick a background for light or dark pages

Keep transparency for logos and icons. Choose white if you're sending the PNG to someone whose viewer shows transparent areas as black.

Need a different size?

Convert first, then change dimensions with Resize Image, or shrink the file with Compress Image File.

Troubleshooting

"Not a valid WebP image"

The file may be corrupted or renamed from another format. Re-download it, or open it in a browser to check that it displays.

"Image is too large to convert"

Your browser couldn't allocate memory for that many pixels. Try a computer, close other tabs, or shrink the image first.

The PNG has a black background

Some viewers show transparency as black. Set Background to White and convert again.

Only the first frame appears

That's expected for animated WebP. This tool saves still images only.

Download all only saved some files

Your browser may block several downloads at once. Allow multiple downloads for this site, or use the Download buttons one at a time.

File won't load

Check that it's a .webp file under 50 MB. Other formats are skipped.

Glossary

WebP
An image format from Google that supports lossy and lossless compression, transparency and animation. It's built for small files on the web.
PNG
Portable Network Graphics, a lossless image format with full transparency support, widely accepted by editors, apps and print services.
Lossless compression
Compression that keeps every pixel exactly as it is. PNG always uses it.
Lossy compression
Compression that throws away some detail to shrink the file. WebP can use it, and JPG always does.
Alpha channel
The part of an image that stores transparency. It's what lets a logo sit on any background.
Canvas
A browser feature that draws images in memory. This tool uses it to decode the WebP and write the PNG.

Frequently asked questions

Is this WebP to PNG converter really free?

Yes. There is no fee, no account, no watermark and no daily limit. Convert as many WebP images as you like, up to 30 files at a time.

Are my images uploaded to a server?

No. Your images are processed in your browser and are never uploaded. The page makes no network requests while you convert.

Does PNG keep the transparent background of my WebP?

Yes. By default the transparent areas stay transparent in the PNG. You can also choose a white or black background in the settings.

Will the PNG look worse than my WebP?

No. PNG is lossless, so the pixels you see in the WebP are saved exactly. A lossy WebP will not get its lost detail back, though.

Why is the PNG bigger than the WebP?

WebP usually compresses much better than PNG, so the PNG is often larger. That is normal. If size matters, try the JPG option or compress the result.

Can it convert animated WebP files?

Only the first frame is saved. PNG here is a single still image, and this tool does not build animations.

Do I need to sign up or install anything?

No. There is no login, no download and no extension. Open the page, add your WebP files, click Convert to PNG and save the results. It works in current Chrome, Safari, Firefox and Edge.

Does it work on my phone?

Yes. Tap the box to pick WebP images from your phone or tablet, convert, and download the PNGs. Buttons are at least 44 pixels tall. Very large images are safer on a computer because phones have less memory.

What is the difference between WebP and PNG?

WebP is designed for small web files and can be lossy or lossless. PNG is always lossless and is accepted almost everywhere, but its files are usually larger. Both support transparency.

Does it work offline?

Once the page has loaded, conversion needs no internet connection, because it runs in your browser and makes no network requests. You do need to be online to open the page the first time.
